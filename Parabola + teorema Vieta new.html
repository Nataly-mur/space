Теорема Виета

Для уравнения ax² + bx + c = 0 при a ≠ 0:
x₁ + x₂ = −b/a, x₁ · x₂ = c/a

1.0 -5.0 6.0
D > 0 — два корня
1.0x² − 5.0x + 6.0 = 0
x₁ + x₂ = 5.0 ( = −b/a )
x₁ · x₂ = 6.0 ( = c/a )
x₁ = 2.0, x₂ = 3.0
Корни целые — удобный пример
💡 a > 0 — ветви параболы вверх; a < 0 — ветви вниз.
💡 Сумма корней = −b/a, произведение = c/a.
💡 При a = 1 формулы упрощаются: x₁ + x₂ = −b, x₁ · x₂ = c.
💡 Если D < 0 — корней нет, теорема Виета неприменима.
